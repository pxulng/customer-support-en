# Procedure 05: Order change and cancellation
> Fictional procedure (synthetic data).

## Rules
- Cancellation or change possible as long as the order has not shipped (status "in preparation").
- Once shipped, the order can no longer be cancelled: the customer must follow the return procedure (sheet 02).
- Refund of a cancelled order: within 7 working days.

## Common cases
- **Change of address or size before shipping**: change the order if stock allows.
- **Cancellation before shipping**: confirm the cancellation by email.
- **Order already shipped**: explain that it can no longer be cancelled and give the return procedure.

## To escalate
- Order whose status is inconsistent (cancelled but shipped)
- Customer who demands cancellation after shipping citing an urgent reason
